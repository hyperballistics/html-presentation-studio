# 开场页实体

## 用途

存放开场章节已写回的 HTML 页面。

## 主要内容

每个已登记页面由一个独立 HTML 文件承载，路径与顺序见[清单](../../../deck.manifest.json)。

| 文件 | 说明 |
|---|---|
| [`README.md`](README.md) | 索引开场章节的页面实体并说明维护约定。 |
| [`p01-ai-pilot.html`](p01-ai-pilot.html) | 「从一个场景开始」示例页，包含 `slide-model`、讲者备注和静态投影。 |

## 维护边界

以 `slide-model` 为内容维护源，通过工作台或工具更新静态投影。章节语境见[章节说明](../section.md)。
