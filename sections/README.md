# 演示章节

## 用途

存放当前清单登记的章节说明和演示页实体。随包内容是试用示例。

## 主要内容

每节包含 `section.md` 和 `pages/`，可先查看[随包示例章节](01-intro/)。从[叙事索引](../STORYLINE.md)定位，再用[清单](../deck.manifest.json)确认顺序与路径。

| 文件 | 说明 |
|---|---|
| [`README.md`](README.md) | 介绍章节目录结构，指向叙事索引、清单和示例章节。 |

## 维护边界

涉及页语义、增删或调序时，同步维护清单和叙事索引。章内说明以 `section.md` 为准。
