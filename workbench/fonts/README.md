# 本地字体资产

## 用途

为工作台和导出件提供随包分发的离线字体。

## 主要内容

| 文件 | 说明 |
|---|---|
| [`README.md`](README.md) | 索引离线字体及对应许可证。 |
| [`SourceHanSans-OFL.txt`](SourceHanSans-OFL.txt) | 思源黑体 SC 的 SIL Open Font License 文本。 |
| [`SourceHanSansSC-VF.ttf.woff2`](SourceHanSansSC-VF.ttf.woff2) | 随包分发的思源黑体 SC 可变字体，主要用于中文。 |
| [`SourceSans3-OFL.txt`](SourceSans3-OFL.txt) | Source Sans 3 的 SIL Open Font License 文本。 |
| [`SourceSans3VF-Upright.ttf.woff2`](SourceSans3VF-Upright.ttf.woff2) | 随包分发的 Source Sans 3 直立可变字体，主要用于英文和数字。 |

## 维护边界

分发时保留字体与对应许可证。字体用途与分发要求见[设计标准](../../agents/design.md#字体分发)。
